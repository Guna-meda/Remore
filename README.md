# Remore – Landing & Onboarding Website

This repository contains the marketing and onboarding website for Remore.  
The website helps users understand the product, see how it works, and complete onboarding before interacting with the WhatsApp bot.

## Purpose

- Introduce the WhatsApp AI assistant
- Explain product capabilities and user workflow
- Showcase UI mockups and usage examples
- Handle user onboarding:
  - Phone number collection
  - WhatsApp OTP verification
  - Location capture
  - Plan selection (free trial and paid plans)
- Enable users to start chatting with the WhatsApp bot

## Scope

This repository only contains the website.  
The WhatsApp bot logic, AI processing, and message handling are implemented in a separate backend repository.

## Notes

- UI and UX focused project
- Built as the primary entry point for the product
- Designed to support future payment and subscription integrations

## Run Locally

npm install  
npm run dev
